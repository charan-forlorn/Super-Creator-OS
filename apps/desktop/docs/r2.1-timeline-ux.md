# R2.1 — Production Timeline UX

R2.1 extends the R1 timeline **without replacing the CommandBus architecture**.
It adds multi-selection and group editing with exact undo/redo, plus enriched
keyboard editing — the highest-value foundational editor capability (R2 priority
model: P1 TIMELINE_EDITING_UX).

## What changed

### CommandBus: atomic `batch` primitive (`packages/command-system/src/bus.ts`)
A new `bus.batch(items)` applies several registered sub-commands as **one
undoable unit**. This is the foundation for exact group undo/redo:
- Every sub-item must be a registered command type (fail-closed on unknown).
- Every sub-payload is schema-validated **before** any mutation.
- If ANY sub-command throws, state is unchanged — the whole batch is rejected.
- The entire batch is recorded as exactly **one** undo entry. Undo replays each
  sub-inverse in reverse order; redo replays each forward command in order.
- Branching semantics preserved: a new edit after undo still clears the redo future.

### Store (`apps/desktop/src/store.ts`)
- `selectedClipIds: string[]` (multi-selection) added alongside the existing
  single `selectedClipId` (which mirrors the primary selection so Inspector /
  AICommandBar need no changes).
- `toggleClipSelection`, `selectAllClips`, `clearClipSelection`.
- `deleteSelected` / `splitSelected` / `duplicateSelected` now act on the full
  selection and collapse to one undo via `bus.batch`.
- `commitGroupMove(deltaSec)` shifts every selected clip by `delta`, clamping the
  **whole group's** minimum start to 0 so relative spacing is preserved (a drag
  near the left edge keeps clip ordering).

### Timeline (`apps/desktop/src/components/Timeline.tsx`)
- Ctrl/Shift+click toggles clips in/out of the selection; plain click selects one.
- Background click clears selection (unless a modifier is held).
- Group drag: the primary clip previews live; on mouse-up the whole selection is
  committed as one `commitGroupMove` (single undo entry).
- Trim (left/right) edits the primary clip; multi-clip trim is intentionally
  single-target to avoid destructive ambiguity.
- Split-at-playhead now splits **every selected clip** at its local playhead
  offset (each must be interior) as one undo unit.
- Selected clips show a green outline; the primary (last-clicked) clip shows a
  stronger blue outline + count badge ("N selected").

### Keyboard (`apps/desktop/src/hooks/useKeyboard.ts`)
| Key | Action |
| --- | --- |
| `Ctrl/Cmd+Z` | Undo |
| `Ctrl/Cmd+Shift+Z` / `Ctrl+Y` | Redo |
| `Ctrl/Cmd+A` | Select all clips |
| `Ctrl/Cmd+D` | Duplicate selection |
| `Esc` | Clear selection |
| `Delete` / `Backspace` | Delete selection |
| `S` | Split selection at playhead |
| `←` / `→` | Nudge selection by 0.5s (`Shift` = 0.1s fine) |
| `Space` | (play toggle reserved for Preview) |

## Non-goals (out of R2.1 scope)
- Marquee/rubber-band selection drag (deferred; click + Ctrl/Shift and Select-All
  cover the milestone; add in R2.1.x if friction remains).
- Per-clip independent trim of multi-selection (kept single-target by design).
- Ripple/slide edits (deferred to later timeline milestone).
